## C 第一阶段重点验证什么

三个工具都验证空闲接收、同会话展示、新会话重置、权限生效和身份刷新。

Codex 提供 queue --resume，但恢复失败也可能成功退出。OpenCode 的服务与原生客户端必须绑定同一 session。Claude 的消息 hook 与会话重置分别验证。

## D 直接派发保持多简单

```sequence num
主 agent -> AgentFlow: 分配下一项工作
AgentFlow -> 执行者: 按配置重置并重新注入角色
执行者 -> 主 agent: 执行、验证、回报结果
主 agent -> 执行者: 检查后继续分配
```

没有独立工作 ID、领取凭证或强制验收操作。内部消息 ID 和恢复日志用于投递确认及排查。

## E 什么情况下继续恢复

可恢复错误采用退避，不因固定次数用尽而结束工作流。依赖恢复后自动继续。投递结果不明时先对账，避免盲目重复执行。

同一工作优先恢复原会话。用户主动关闭成员则停止该成员。工作完成后待命。

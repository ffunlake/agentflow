## 已实现

- `internal/store/control.go`：已有库打开（只读或可写，不创建/迁移）、同一事务读取 run/current seats、原子 stop intent。停止标志与 STOP_REQUESTED journal 在同一事务提交；BEGIN IMMEDIATE 跨句柄串行化，重复请求返回原序号和时间。journal 写入失败回滚停止标志。
- `internal/runtime/status.go`：`ReadStatus`、`QueryAttach`、`RequestStop` 可复用模型。冻结数据库配置补出未注册 seat，当前数据库 generation/native/status 覆盖初始值；独立检查不可变快照与 run/config digest，保留可读的部分结果。角色绑定按 agent ID 排序，不依赖屏幕位置。缺失锁不推断停止或允许恢复；匹配 run 的锁提供 PID 与有界 socket 诊断，隐藏 token。
- `internal/cli/control.go`：`status/attach/stop --run ID [--run-dir DIR] [--json]`，接入既有帮助与错误前缀。默认 `$XDG_STATE_HOME/agentflow/runs/ID`，回退 `~/.local/state/agentflow/runs/ID`；目录内 state.db/config.resolved.json/coordinator.lock。socket 只使用匹配 run 的锁中已有路径。
- README、runtime API 说明和实施计划同步最小范围及真实验证边界；原 S4.3 完整出口保持未勾选。

## 结果与退出码契约

`status` 的 `status=PARTIAL` 和 `runtime_communication=UNVERIFIED` 保留整体能力边界。`run.status` 为 STARTING/PARTIAL/REGISTERED 或 STOP_REQUESTED；`run.startup_phase` 是持久原值，`run.startup_progress` 是从注册记录推导的进度，均不证明进程存活或工具执行。`seats` 含 run/agent/generation/tool/status/native，另含冻结的 cwd/role/permissions/session。快照缺失/损坏时仍可读到数据库 seat；历史代际不会替代 current 代际。

`attach` 的 `run_id/workspace_id/socket_path` 只返回已有定位证据。一致的持久 seat workspace 可补足空 run workspace；多 workspace 冲突时留空。始终 `status=PARTIAL`、`attached=false`、`runtime_communication=UNVERIFIED`、退出 1，不伪造 attach 成功。

`stop` 成功返回 `run_id/status=STOP_REQUESTED/journal_seq/recorded_at/executed=false`、退出 0。重复调用（含不同 CLI 进程）返回完全相同 JSON。损坏或缺失快照/锁不妨碍写停止意图。没有 kill、关闭 cmux、删除快照、自动重启或恢复行为。

参数错误退出 2；状态无诊断时退出 0（包括无锁），读取/身份/产物错误与未验证 attach 退出 1。JSON 报告写 stdout，稳定 `agentflow: error:` 诊断写 stderr。稳定诊断如下：

| code | path | 含义 |
|---|---|---|
| STORE_UNAVAILABLE | store.path | 缺库、损坏数据库或不支持 schema；不创建或迁移 |
| RUN_NOT_FOUND | run.run_id | 空库或 stop 找不到目标 run |
| RUN_MISMATCH | run.run_id | status/attach 请求 run 与库身份不同 |
| STORE_READ_FAILED | run.run_id | 无法读取一致的 run/seats 状态 |
| CONFIG_SNAPSHOT_INVALID | run.config_snapshot | 数据库冻结配置无效或 digest 不一致 |
| SNAPSHOT_MISSING / SNAPSHOT_INVALID / SNAPSHOT_MISMATCH | snapshot.path | 缺失、损坏/不安全、run/config 身份不匹配 |
| SEAT_MISMATCH | seats.ID 或 seats.ID.tool | 当前角色或工具不匹配冻结配置 |
| SEAT_BINDING_INVALID | seats.ID.native | READY 缺少完整原生绑定 |
| LOCK_INVALID / LOCK_RUN_MISMATCH | lock.path / lock.run_id | 锁损坏或其他 run 的锁，不探测其 socket |
| WORKSPACE_CONFLICT / WORKSPACE_UNVERIFIED | run.workspace_id | 已知 workspace 冲突或无唯一定位 |
| ATTACH_UNVERIFIED | attach.attached | 未实现/验证真实 cmux attach |
| STOP_INTENT_FAILED | run.run_id | 意图事务或已有意图一致性失败 |

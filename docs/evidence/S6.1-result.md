## 实现与文件契约

- [context/model.go](../../internal/context/model.go)：version 1 的 Snapshot、Protocol、S5 MessageProtocol、Section、Reference、Manifest/Entry；角色、背景、决策、进度、未完成事项分别保存。每段至多 8192 字节和 16 个引用，详细证据保留路径引用，角色 prompt 通过冻结运行快照和字段引用定位。
- [context/run.go](../../internal/context/run.go)：`Create/Open/Run.Agent` 绑定绝对 context_dir、run、agent、lead 与配置摘要，run.json 和 agent.json 防止目录置换、跨身份写入。run 与 revision 排他创建。
- [context/files.go](../../internal/context/files.go)：真实目录逐层打开、os.Root 约束、目录 0700、普通文件 0600、no-follow 与 inode 核对；同目录随机临时文件、fsync 和 hard-link 原子无覆盖发布，目录 fsync。
- [context/snapshot.go](../../internal/context/snapshot.go)：每个 revision 包含 role/background/decisions/progress/pending 与 manifest。manifest 最后提交，固定记录文件路径、用途、SHA-256 和逻辑更新时间；读回同时校验全套文档，拒绝混合版本、缺文件、错误身份、版本/载荷/时间/摘要错误、未知字段、尾随数据和越界路径。
- [runtime/context.go](../../internal/runtime/context.go)：`CreateContext(snapshotPath, runID)` 从现有冻结 RunSnapshot 创建所有 agent 的 `initial` 文件，不读原始 prompt_file。S5 身份、ACK 接收含义与终态报告声明成为角色协议的一部分；实时状态仍以既有 store 为准。

目录约定：`<context_dir>/<run_id>/run.json`、`<agent_id>/agent.json`、`<agent_id>/<revision>/{role,background,decisions,progress,pending,manifest}.json`。主 agent 使用自己的目录发布摘要，其他 agent 使用各自目录。没有新增 CLI 或依赖。

## 测试证据

| 场景 | 实际验证 |
|---|---|
| 持久读回与新 revision | 首版重开后逐字段一致，新 revision 不改变旧版，所有目录/文件精确为 0700/0600 |
| 双 run、双 agent | 两 run 共用 context_dir、每个 run 两个 agent；四组摘要独立更新、重新打开、读回；跨 agent/run Snapshot 拒绝 |
| 冻结 prompt | Resolve 后写入运行快照，再删除 prompt_file；两个 run 均可创建上下文，prompt 摘要匹配，全部上下文文件不含完整 prompt |
| 重复与并发 | 重复 run/revision 拒绝；12 个并发发布恰好一个成功，其余 ErrExists，成功版本完整可读 |
| 中途未提交 | 手工创建无 manifest 的 revision，读回 ErrCorrupt，重复发布 ErrExists；保留失败证据，不自动覆盖 |
| symlink / 非私有 | base/run/agent/revision/manifest/document/run 描述/agent 描述逐层替换为 symlink 或公开权限均拒绝；源运行快照及祖先 symlink 也拒绝 |
| 目录置换 | agent 真目录搬到其他 agent 或其他 run 的相同 agent 位置，描述不匹配，写入前拒绝 |
| 身份、摘要、路径 | run/agent/config 错配、未知 agent、相对/穿越/NUL/非法 ID、重复 agent、manifest 任意/重复路径均拒绝 |
| 损坏与 schema | 文档删改、manifest 缺失、SHA-256 不符、未知字段、尾随 JSON、null、畸形/超大文件、时间/版本/文档身份/协议错误均拒绝；更新 manifest 摘要后仍检查文档 schema |
| 临时文件与无覆盖 | 原子发布 helper 对已有文件和 symlink 返回 ErrExists，目标原文保留，临时文件清理 |
| S5 语义 | 角色协议固定 ACK=receipt_only、report=agent_claim，终态 DONE/FAILED/BLOCKED_CONFIRM；错误 ACK 语义拒绝 |
| JSON 转义体积 | 单字段长度合规、转义后超过 128 KiB 的文档在创建 revision 前被拒绝，避免发布无法读回的版本 |

## 边界与下一步

引用目标是描述性来源，本包不读取或复制引用文件；只有管理的五份文档由 manifest 校验。SHA-256 检测损坏，不提供签名认证。权限与 API 绑定适用于个人/小团队同一用户协作，不能阻止同一 OS 用户的恶意进程绕过 API。失败可能留下部分 run 或 revision；缺少 manifest 不可读，重复名称不覆盖，调用方显式检查后选择新 revision。

## 实现产物

- `internal/context/bootstrap.go`：Latest 验证全部可见 revision，按提交 manifest 的更新时间选最新，同时间以 revision 名字排序；未提交/损坏不回退。PrepareBootstrap 读取身份绑定的角色/背景/决策/progress/pending，以及当前代际最新自身报告；lead 可恢复经原报告/证据/SHA/摘要/引用列表重验证的 Merge 产物。
- `internal/runtime/bootstrap.go`：NewBootstrapService 的 Bootstrap/Rebuild 别名 API。SQLite immediate 事务覆盖当前 run/agent/generation、完整冻结配置摘要、context 路径/lead/成员、seat 工具/workspace、角色/cwd/permissions/session/prompt digest 和报告原派发绑定检查，以及实际文件读取/发布。
- `internal/store/report.go`：WithBootstrapContext 复用 S6.2 门禁并向回调提供同事务的 Run/Seat；原 WithReportContext 使用同一基础。BEGIN IMMEDIATE 在文件操作期间阻止其他数据库句柄切换代际，不改变 seat/message/delivery/ACK/journal。
- `internal/cli/bootstrap.go`：`rebuild|bootstrap --run ID --agent ID --generation N [--run-dir DIR] [--json]`。从现有 state.db 的冻结配置定位 context，不创建/迁移数据库。成功退出 0，身份/文件故障退出 1，参数错误退出 2。
- bootstrap 写为 `<context_dir>/<run>/<agent>/.bootstrap/g-N/<content-sha256>.json`；0700/0600、临时文件/fsync/hard-link 无覆盖发布，最多 128 KiB。重复/并发/跨进程请求复用同一内容路径；已有缓存字节损坏直接拒绝。

包中包含角色协议、cwd/permissions/session policy、当前 progress/pending、report/evidence 引用、持久化 seat 坐标、恢复建议及 next。pending 优先于报告 next，空值给出核对进度的建议。fresh 建议新建会话并独立 READY；persistent 建议先核实旧绑定，不可用时从文件创建新会话。stop intent 保留并提示先处理停止意图。两种模式均无 native 操作。

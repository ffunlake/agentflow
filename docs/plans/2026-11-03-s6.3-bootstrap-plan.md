任务 `s6-session-rebuild`，session `655d29c6-031f-4cc6-af78-2ca4b495bb2c`。

采用文件 bootstrap + 当前 store 事务门禁。以 run/agent/current generation 定位身份；同一 immediate 事务覆盖冻结配置、当前 seat、context 路径/成员、角色协议、最新 revision 和报告绑定验证，以及 bootstrap 无覆盖发布。相较直接执行 session reset，此方案可离线验收且保留工具适配器的真实 READY 边界；相较将恢复内容写入消息数据库，不增加 schema 或依赖。

最新 revision 按 manifest 更新时间选择，同时间以 revision 名字排序。所有可见 revision 必须完整可验证，未提交/损坏则拒绝，避免回退旧进度。执行者只读取自己的 revision/当前代际最新报告；主 agent 可读取经完整重验证的 Merge 摘要及其执行者报告引用。源 prompt、聊天、证据正文不复制进包。冻结 prompt 仅保留字段引用与 SHA。

恢复包包括 role/tool/cwd/permissions/session policy、当前进度/pending、独立报告与证据路径、持久化 seat 坐标、恢复建议及下一步。fresh 建议新会话并独立 READY；persistent 建议验证旧会话，不可用时从文件创建新会话。生成结果固定 `executed=false`、communication `UNVERIFIED`；不改变 seat、generation、消息、ACK 或报告。bootstrap 内容 SHA 定址，重复请求复用相同文件，损坏缓存拒绝。
